Notification Center
Контекст
Задание предназначено исключительно для оценки технических знаний и навыков кандидата. Выполненная работа не передается компании и не используется в коммерческих целях. Кандидат вправе разместить код в открытом доступе с любой лицензией на свое усмотрение.
Задание проверяет умение реализовать сквозную фичу: сервис на Theia backend и виджет на frontend, связанные типизированным RPC-протоколом.
Задача
Реализовать систему уведомлений: backend-сервис публикует типизированные уведомления, frontend отображает всплывающие сообщения/toast и ведет историю уведомлений в боковой панели.
Функциональные требования
Backend – NotificationService (Theia backend)
Типизированный RPC-интерфейс. Структура уведомления:
{ id: string, severity: ‘info’ | ‘warning’ | ‘error’, title: string, message: string, actions?: { label: string, id: string}[]}.
Push-событие. При вызове push() сервис немедленно отправляет событие на frontend через Theia event bus.
Метод getHistory(): Promise<Notification[]>. Возвращает последние 100 уведомлений в хронологическом порядке. Хранит in-memory.
При превышении лимита в 100 записей старые вытесняются.
Frontend – Notification Panel
При получении события onNotification показывает уведомление/toast (MessageService или кастомный overlay). Уведомления/toast автоматически скрывается через 5 секунд для info/warning. Error – остается до явного закрытия.
Кнопки из actions[] отображаются в уведомлении/toast; клик отправляет событие actionInvoked(…) на backend.
TreeWidget или ReactWidget в боковой панели со списком всех уведомлений. Иконка severity слева от каждой записи (info / waning / error). Метка времени а формате HH:MM:SS. Клик на запись с actions[] разворачивает кнопки действий.
Фильтрация по severiry (три чекбокса в тулбаре)
Кнопка «Очистить все» в тулбаре.
Нефункциональные требования
Типизированный RPC протокол в common/-пакете – общий интерфейс для frontend и backend.
Подписки на события корректно освобождаются.
Будет плюсом:
Тесты для backend.
Сохранение истории уведомлений при перезапуске
Группировка уведомлений по дате (Сегодня/Вчера/Раннее)
Анимация появления/исчезновения уведомлений.
